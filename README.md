# Mathematically Correct data

Daily stats for the Mathematically Correct mod for Slay the Spire 2, one table per game build. The files are in the `community` release.

The tables are built from community run histories in the [Spire Codex](https://spire-codex.com) export. Only base-game runs are used, and Steam IDs, seeds and other player identifiers are removed. Thanks to Spire Codex for collecting and sharing the runs.
